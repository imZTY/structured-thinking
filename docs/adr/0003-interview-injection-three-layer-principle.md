# ADR-0003: 访谈结论注入认知框架的三层分流原则——能解释不展开

- Status: Accepted
- Date: 2026-10-27
- Deciders: zengtianyi
- Related: ADR-0002

## Context

拿到一份深度访谈纪要后，如何把它融进已有认知框架？本次（2026-10-26 白宇访谈）面临的真实抉择：访谈最大的结论是「初始流量是立项的硬门槛」，现有框架把「作者势能」埋在 `签约可行性 → 预期销量 → 触达率` 第 4 层当加分项。AI 第一轮方案主张重构公式（把事前过程改成流量主导），被用户收回；最终采纳的分流原则效果好——改完用户评价「现在通顺多了」。同时确立配套标准：**描述层（note/details）没有硬标准，只要把事说清楚就行**，不必为追求形式完美而过度动公式。

## Decision

访谈结论按「能不能用现有公式解释得通」分流，优先级从低侵入到高侵入：

1. **第一优先：note/details 能解释得通的，不动公式**——业内人士观点作为公式元素的补充解释注入对应词的描述层，防止使用者误解即达标。例：流量门槛数字写进 `签约可行性` 与 `自有触达` 的 note，公式不动。
2. **第二优先：公式本身会误导人的（违反 ADR-0002）才动公式**——且修复走「改造右边同维度」路径，不走推倒重构。例：版税双轨制内容量大，但因不违反判定标准，选择加厚 note 而非展开成公式。
3. **判据**：改公式的标准是「这条公式现在会误导人」，不是「访谈提了个新话题」。访谈者说「框架 80% 正确、缺失一些维度」时，正确应答是补维度和权重，不是换模型。

描述层的配套标准：没有强标准，说清楚即可；但**事实性数字必须区分「已校准」与「待校准」**，未覆盖的项显式标注「首轮访谈未覆盖」，防止使用者误以为已校准。

## Options Considered

1. **按访谈结论重构公式**（AI 第一轮方案：事前过程改为流量主导）——否决：访谈者认可框架主体，被否定的只是完整度与权重；重构等于把「下次访谈要校准的东西从树上摘掉」。
2. **只在描述层打补丁，公式永不改** —— 否决：违反 ADR-0002 的公式会误导人，note 救不了假算术；本次仍有 3 条公式必须修。
3. **三层分流原则** —— 选用：以「误导风险」为唯一动公式的触发条件，兼顾框架稳定性和事实正确性。

## Consequences

**正面**：
- 框架结构稳定，树的演化有节制；业内观点以最低侵入进入，PR 审阅时公式 diff 即「结构决策」，note diff 即「事实更新」，天然分层。
- 「已校准/待校准」标注让框架成为诚实的事实账本，未覆盖项反而是下次访谈的现成议程。

**负面**：
- note 变厚（如 `签约可行性` 的 note 同时承载比值逻辑与流量门槛），信息密度高，阅读负担增加。
- 「会误导人」的判断依赖人工，分流决策有主观性。

**风险 / 后续行动**：
- 大块新知识（如版税双轨制）塞 note 是权宜，若后续访谈持续加厚到 note 装不下，应重新评估展开——note 超过约 200 字是展开的信号。

## Good Cases

- 流量门槛（小红书 5 万 / B站 10 万 / 全网 50 万）→ 注入 `签约可行性` 与 `自有触达` 的 note，公式未动，误解已消除。
- 三审三校 3–5 个月、自费起步约 10 万、立项五维度 → 全部 note 层注入。
- 「提前公开不影响销售」从 idea 升格 action，依据写进 text——行动层验证强度足够时允许升格。

## Bad Cases

- AI 第一轮的 `作者势能 = 专栏化选题池 + 视频化分发 + 提前公开` 展开提案：动机是「访谈增量内容没有家」，但归属判断错误（专栏化属于写作履历范畴），且不为消除误导、只为装内容而展开——**「没地方放内容」不是展开公式的理由，公式展开只为消除误导或表达真实构成**。
- 原框架 `版税率` note 写「常见 6%–10%，新人多在低端」：访谈证实为 **8%–10% 阶梯起步**——未经校准的行业区间数字写成肯定语气，会误导使用者。教训：待校准数字一律带「待校准」标记。
