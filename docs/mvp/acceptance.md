# MVP 验收清单

启动:`npm install && npm run dev`,打开终端里打印的地址(默认 http://localhost:5173/structured-thinking/)。

只有 `npm run dev` 能编辑,改动 0.5 秒内自动写回 `content/`。线上部署(GitHub Pages)是只读的,右上角显示「只读」。

## 读:认知模式(白天)

- [ ] 首屏是「稳定性治理」的根公式 `稳定性 = 结果指标 + 过程指标`,下面缩进展开了第二层
- [ ] 公式里每个词的下划线含义:粗实线 = 已展开,点线 = 有公式但收起,无线 = 还没有公式
- [ ] 点一个有公式的词,它的公式铺在这一行正下方;再点一次收起
- [ ] 继续点「可用性」「MTTR」,能一直往下推导,没有层数限制
- [ ] 选中一个词后右侧检查器显示:路径、它的公式、本质问题、说明、详情
- [ ] 在公式外的空白处点一下,或按 Esc,取消选中,检查器回到主题概述
- [ ] 工具栏「展开 2 / 3 / 全部 / 收起」可用
- [ ] 浏览器前进 / 后退、刷新后选中的词保持;分享链接能直接打开到某个词
- [ ] 左下角切换到「AI 知识库」,根公式是 `端到端质量 ≈ 检索质量 × 生成质量`

## 写:认知模式

- [ ] 点一个没有公式的词(如「容量水位」),出现输入框,写右边回车,公式就展开了
- [ ] 写到一半按 Esc,取消,什么都不留下
- [ ] 悬停在一条公式上,出现 ✎,可改它的右边
- [ ] 把右边的一个词改名,它下面已经展开的子公式跟着改名,不会丢
- [ ] 删掉右边的一个词,提示「已移除 N 个下层词」,⌘Z 可以找回
- [ ] 右边写了第二个等号,报错提示,输入内容不丢
- [ ] 选中文字按 ⌘B 把它包成 `[ ]`,成为一个整体词
- [ ] 检查器里可改本质问题 / 说明 / 详情;「取消展开」删除某个词的公式
- [ ] ⌘Z / ⇧⌘Z 撤销重做,磁盘上的 JSON 跟着变
- [ ] 左下角 `＋` 新建主题,创建后直接进入根公式编辑,`content/manifest.json` 里已登记

## 行动模式(黑夜)

- [ ] 点「行动」,整个界面变成黑夜主题;再点「认知」回到白天
- [ ] 行动模式下公式只读:没有 ✎,点没有公式的词不会进入编辑,检查器没有认知字段输入框
- [ ] 选中一个词,检查器下半部是「行动层」,可以添加「动作」或「想法」
- [ ] 动作前有状态圆圈,点击在 待办 ○ → 进行中 ◐ → 完成 ● 间循环;想法没有状态
- [ ] 有行动的词上显示数量徽标
- [ ] 认知模式下看不到任何行动内容

## 写旅程(手写或 AI 生成)

- [ ] `npm run validate` 通过
- [ ] 复制 `content/topics/_template` 为新主题,登记到 `manifest.json`,校验通过后刷新页面能看到新 tab
- [ ] 故意写错(子公式左边与父公式里的词不一致、`terms` 的键不在公式右边、重复 `id`),校验器报出清晰的错误
- [ ] 开发服务拒绝写回非法内容,磁盘文件不变

## 工程

- [ ] `npm test` 36 个单测全过
- [ ] `npm run build` 通过;`npm run preview` 下页面只读,Service Worker 已注册
- [ ] 手机宽度下公式自动换行,检查器移到下方
- [ ] 手机浏览器打开,可「添加到主屏幕」

## 已知边界(有意不做)

- 线上部署不能编辑(没有后端);账号、协同、云端存储
- 选中文字后用鼠标「选词成锚点」:目前用 `[ ]` 或 ⌘B 手动成词
- 跨公式共享同名词的子树:同名词各自独立
- 关联(`links`)和参考资料(`refs`)只能在 JSON 里维护,检查器只读展示
- 3D 渲染、一键转架构图
- 种子内容的正式转换:当前两个主题是验证标准用的 demo
